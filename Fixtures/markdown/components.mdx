# Using Greece in your docs

Greece previews MDX without running it. Expressions like {meta.sidebar} show as code
and comments disappear{/* like this one */}.

<Callout type="warning" title="Before you start">
  Quick Look extensions only run after the app has been **opened once**.
</Callout>

<Tabs items={['Finder', 'Terminal']}>
  <Tabs.Tab>
    Select a file and press **Space**.
  </Tabs.Tab>
  <Tabs.Tab>
    ```sh
    qlmanage -p README.md
    ```
  </Tabs.Tab>
</Tabs>

<Chart kind="bar" data={[12, 19, 7]} title="Previews per day" />

<Steps>
### Install
Download Greece and move it to Applications.

### Enable
Turn it on in System Settings.
</Steps>
