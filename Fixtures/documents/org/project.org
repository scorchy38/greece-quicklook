* Overview
The timetable service publishes sailings for eleven routes across the
archipelago. This rewrite moves it from nightly batch files to a live feed, so
that delays reach passengers *within a minute* instead of the next morning.
See [[https://orgmode.org][Org mode]] for the format of this file, or
https://example.org/ferries for the current public site.

Goals, in order of importance:
1. Correct departures, always[fn:1].
2. Delays published in under 60 seconds.
3. A feed other apps can use without asking us.

** Glossary
- Sailing :: one departure of one vessel on one route.
- Rotation :: the sequence of sailings a vessel runs in a day.
- Tidal window :: hours when a harbour is deep enough for the larger vessels.

#+BEGIN_SRC python
def delay_minutes(scheduled, estimated):
    """Rounded delay in minutes; early arrivals count as on time."""
    seconds = (estimated - scheduled).total_seconds()
    return max(0, round(seconds / 60))
#+END_SRC

#+BEGIN_NOTE
The receiver drops roughly one position in forty during storms. The estimator
must tolerate gaps of up to two minutes.
#+END_NOTE

** NEXT Choose the arrival model                                :research:
Candidates are a constant-speed model and a per-route regression. Expected
error for the constant-speed model is about \(\pm 90\) seconds; the
regression should halve it. Euler would approve: \(e^{i\pi} + 1 = 0\).
