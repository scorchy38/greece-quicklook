# App, installer and binary fixtures

Everything here was built on this Mac for Greece's tests. Nothing is copied from real products, and every
signing identity is a throwaway self-signed certificate.

## Apps, binaries, profiles and torrents

Rebuild with `python3 Fixtures/apps/recipe/plists.py && zsh Fixtures/apps/recipe/build.sh <repo>` (Xcode 26.6,
OpenSSL 4). The recipe writes the Info.plists and entitlements, compiles tiny C and Objective-C programs with
`clang`, signs them ad hoc with `codesign`, and signs the profiles with a fresh self-signed "Apple Development:
Greece Fixture (FIXTURE01)" certificate using `openssl cms -sign`.

| File | What it is |
|---|---|
| `macho/greece-tool` | Universal (arm64, x86_64) command-line tool, macOS 12.0, with an embedded `__TEXT,__info_plist`, signed ad hoc with the hardened runtime and two entitlements. |
| `macho/intel-tool` | x86_64-only tool, for the "Intel only" badge. |
| `macho/libgreece.dylib` | arm64 dynamic library, install name `@rpath/libgreece.dylib`, version 1.2.3. |
| `macho/lib.o` | arm64 object file. |
| `bundles/Tiny.app` | Universal AppKit app: sandboxed entitlements, three usage descriptions, document types, a URL scheme, a privacy manifest, three localizations, a Quick Look extension and a login item. Signed ad hoc with the hardened runtime. |
| `bundles/Tampered.app` | `Tiny.app` with `fr.lproj/InfoPlist.strings` changed after signing. |
| `bundles/Tiny.app.dSYM` | `dsymutil` output for a universal debug build (two UUIDs). |
| `bundles/Tiny.xcarchive` | A hand-assembled archive: `Info.plist`, `Products/Applications/Tiny.app` and `dSYMs/Tiny.app.dSYM`. |
| `ios/Tiny.ipa` | `Payload/Tiny.app` with an arm64 iOS executable (signed ad hoc with entitlements), a binary Info.plist, the development profile below as `embedded.mobileprovision`, and a 120 px icon generated by `icon.py` and crushed to Apple's CgBI format by Xcode's `pngcrush -iphone`. Force-added: `*.ipa` is git-ignored. |
| `profiles/Tiny_Development.mobileprovision` | Development profile (three devices, expires 2036) signed by the throwaway certificate. |
| `profiles/Expired_AdHoc.mobileprovision` | Ad hoc profile that expired in 2025. |
| `profiles/Greece.mobileconfig` | Unsigned configuration profile: Wi-Fi, a web clip, a root certificate and restrictions. |
| `profiles/Greece-Signed.mobileconfig` | The same profile, CMS-signed. |
| `torrent/*.torrent` | Written by `torrent.py`: a private multi-file v1 torrent with tiers and a web seed, a single 4.7 GB file, and a hybrid v1/v2 torrent. |

`*.dSYM` is git-ignored too; the dSYM fixtures were force-added.

## Windows (`windows/`)

Built on this Mac from the sources in `windows/source/` with Homebrew LLVM 22 (`clang`, `lld-link`, `llvm-rc`,
`llvm-dlltool`), Python 3 and OpenSSL. Rebuild with `Fixtures/apps/windows/source/build.sh <work-dir>`. No C
runtime, nothing downloaded.

| File | What it is |
|---|---|
| `hello.exe` (7 KB) | x64 GUI program importing `kernel32.dll` and delay-loading `user32.dll`, with an icon (a BMP and a PNG entry), an administrator manifest, version info for "Hello Greece" 1.2 by "Greece Fixtures", `/Brepro` and a CodeView record. |
| `greece.dll` (2 KB) | ARM64 library exporting two functions by name and one by ordinal only. |
| `hello-signed.exe` (9 KB) | `hello.exe` with a self-signed test signature in Authenticode's layout (OpenSSL `cms -sign` over the file's SHA-256 Authenticode digest). It tests parsing and the digest check, not Windows trust. |

## Installer packages (`packages/`)

Built with Apple's `pkgbuild` and `productbuild` from tiny source trees written for these tests.

| File | How it was made |
|---|---|
| `Sample.pkg` (3 KB) | `pkgbuild --root root --scripts scripts --identifier com.example.sample --version 1.2.3 --install-location / Sample.pkg`: an app, a launch daemon plist, and `preinstall`/`postinstall` scripts that are never meant to run. Unsigned. |
| `SampleSuite.pkg` (6 KB) | A product archive from `productbuild --distribution Distribution`: title "Sample Suite", `hostArchitectures="arm64,x86_64"`, macOS 13.0 minimum, two choices, an installation-check script, `RequireRestart` and a plain-text license. Unsigned. |
| `SignedSample.pkg` (5 KB) | `Sample.pkg` re-signed with a classic xar RSA signature by a throwaway self-signed certificate. `pkgutil --check-signature` reports "signed by untrusted certificate". The private key was discarded. |

## Android (`android/`)

Built with the Android SDK (aapt2 and zipalign from build-tools 35, `android.jar` from platform 34, apksigner
and jarsigner from a JDK); `android/recipe/make.sh` rebuilds all three. The signing key is generated fresh on
each run, so tests check names and schemes, not fingerprints.

| File | What it is |
|---|---|
| `sample.apk` (25 KB) | `com.greece.sample` 1.2.3 (42) with a binary manifest and resources, a mipmap icon, sensitive permissions, links, an accessibility service, `debuggable`, stub DEX and `libflutter.so`. Signed with v1, v2 and v3. |
| `adaptive-unsigned.apk` (3 KB) | An adaptive icon only (colour background, vector foreground). Unsigned. |
| `sample.aab` (7 KB) | The sample in Android App Bundle layout (protobuf manifest and resources, `BundleConfig.pb`), signed with jarsigner. |
